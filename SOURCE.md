Transformations: a copy was upgraded with Microsoft's SQL Server Compact 4.0 engine; all22 tables/1224 rows and binary XML were exported without application-object deserialization. `source/database-export.zip` preserves all2470 exported files, including original binary blobs and decoded XML. Stored spectra were decoded and ancestry joined. All216 LZO-compressed spectral tiles were unpacked into sparse count arrays; all135 image pyramids and18 time planes were preserved as typed HDF5 arrays. Every map matches its stored spectrum channel by channel. `source/unreferenced-member.zip` preserves the single unreferenced DAT unchanged (SHA-256 `cd4b9a3bf7589c8d1debd8cc1e8f786b532ad70266a82c2548960864644d6344`). Quantification and calibration blobs remain available without invented semantics. Energy/time units remain inferred; independent AZtec-export comparison is absent.
